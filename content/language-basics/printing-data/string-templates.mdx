# String Templates

<DocSource docs={["strings"]} />

The [`String`](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/) type represents a sequence of [characters](https://kotlinlang.org/docs/characters.html). You can use it for text values, such as words, sentences, messages, or structured text.
