# Why use Kotlin

<DocSource docs={["comparison-to-java","faq"]} />

Kotlin is an open-source statically typed programming language that targets the JVM, Android, JavaScript, Wasm, and Native. It's developed by [JetBrains](https://www.jetbrains.com). The project started in 2010 and was open source from very early on. 0 release was in February 2016.
