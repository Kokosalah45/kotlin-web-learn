# Extension Functions

<DocSource docs={["extensions"]} />

Kotlin _extensions_ let you extend a class or an interface with new functionality without using inheritance or design patterns like _Decorator_. They are useful when working with third-party libraries you can't modify directly. Once created, you call these extensions as if they were members of the original class or interface.
