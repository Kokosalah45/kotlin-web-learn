# Properties

<DocSource docs={["properties"]} />

In Kotlin, properties let you store and manage data without writing functions to access or change the data. You can use properties in [classes](https://kotlinlang.org/docs/classes.html), [interfaces](https://kotlinlang.org/docs/interfaces.html), [objects](https://kotlinlang.org/docs/object-declarations.html), [companion objects](https://kotlinlang.org/docs/object-declarations.html), and even outside these structures as top-level properties.
