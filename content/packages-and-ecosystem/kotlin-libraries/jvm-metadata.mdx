# JVM Metadata

<DocSource docs={["metadata-jvm"]} />

The [`kotlin-metadata-jvm`](https://github.com/JetBrains/kotlin/tree/master/libraries/kotlinx-metadata/jvm) library provides tools to read, modify, and generate metadata from Kotlin classes compiled for the JVM. class` files, is used by libraries and tools such as [`kotlin-reflect`](https://kotlinlang.org/docs/reflection.html) to inspect Kotlin-specific constructs such as properties, functions, and classes at runtime.
