# Kotlin Learn

Every concept from the [roadmap.sh Kotlin roadmap](https://roadmap.sh/kotlin), grouped
under its parent category, with each page written from — and linked to — the
[official Kotlin documentation](https://kotlinlang.org/docs/home.html) and the
[standard library API reference](https://kotlinlang.org/api/core/).

Ten parent categories, 52 topics, 101 subtopics. Every page opens with an
**Official sources** block naming the exact `kotlinlang.org` pages it was written
from, so you can always jump to the authoritative text.

## How these pages are built

The category tree is reconstructed from [`roadmap.sh/kotlin.json`](https://roadmap.sh/kotlin.json)
— its graph edges, section boxes, and node positions — so the grouping matches
the roadmap you are following rather than one invented here.

The prose is written against the Markdown sources of the official docs
([`JetBrains/kotlin-web-site`](https://github.com/JetBrains/kotlin-web-site/tree/master/docs/topics),
Apache 2.0), fetched into a local cache by `pnpm content:fetch`. Every doc and API
link is checked for a `200` by `pnpm content:verify`. See [attribution](/attribution).
