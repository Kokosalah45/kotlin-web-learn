# Throwing Exceptions

<DocSource docs={["exceptions"]} />

Exceptions help your code run more predictably, even when runtime errors occur that could disrupt program execution. Kotlin treats all exceptions as _unchecked_ by default. Unchecked exceptions simplify the exception handling process: you can catch exceptions, but you don't need to explicitly handle or [declare](https://kotlinlang.org/docs/java-to-kotlin-interop.html) them.
