# Write Operations

<DocSource docs={["collection-write"]} />

Write operations change a collection's contents, so they exist only on
`MutableCollection`. This page covers what every mutable collection supports; see
[List-specific](/collection-operations/collection-specific-operations/list-operations) and
[Map-specific](/collection-operations/collection-specific-operations/map-operations)
operations for the rest.

Outputs below come from running `examples/collection-operations/write-operations.kt`.

## Adding elements

`add()` appends a single element:

```kotlin
val numbers = mutableListOf(1, 2, 3, 4)
numbers.add(5)
println(numbers)
```

```text
[1, 2, 3, 4, 5]
```

`addAll()` adds every element of an `Iterable`, `Sequence` or `Array`. Receiver and
argument types need not match. Given an index, it inserts there and shifts the rest along:

```kotlin
val more = mutableListOf(1, 2, 5, 6)
more.addAll(arrayOf(7, 8))
println(more)
more.addAll(2, setOf(3, 4))
println(more)
```

```text
[1, 2, 5, 6, 7, 8]
[1, 2, 3, 4, 5, 6, 7, 8]
```

`+=` (`plusAssign`) appends in place on a mutable collection — an element or a whole
collection:

```kotlin
val words = mutableListOf("one", "two")
words += "three"
println(words)
words += listOf("four", "five")
println(words)
```

```text
[one, two, three]
[one, two, three, four, five]
```

## Removing elements

`remove()` removes **one** occurrence and returns whether anything was removed:

```kotlin
val dupes = mutableListOf(1, 2, 3, 4, 3)
dupes.remove(3)
println(dupes)
println(dupes.remove(5))
println(dupes)
```

```text
[1, 2, 4, 3]
false
[1, 2, 4, 3]
```

The first `3` went; the second stayed. Removing a value that is not there is not an error —
it just returns `false`.

| Function | Effect |
| :--- | :--- |
| `removeAll(collection)` | removes everything present in the argument |
| `removeAll { predicate }` | removes everything matching |
| `retainAll(collection)` | keeps **only** what is in the argument |
| `retainAll { predicate }` | keeps only what matches |
| `clear()` | removes everything |

```kotlin
val retained = mutableListOf(1, 2, 3, 4)
println(retained)
retained.retainAll { it >= 3 }
println(retained)
retained.clear()
println(retained)

val numbersSet = mutableSetOf("one", "two", "three", "four")
numbersSet.removeAll(setOf("one", "two"))
println(numbersSet)
```

```text
[1, 2, 3, 4]
[3, 4]
[]
[three, four]
```

```kotlin
val predicate = mutableListOf(1, 2, 3, 4, 5, 6)
predicate.removeAll { it % 2 == 0 }
println(predicate)
```

```text
[1, 3, 5]
```

### -= repeats the plus/minus asymmetry

As with the [non-mutating operators](/collection-operations/plus-and-minus-operators),
a single element removes its first occurrence while a collection removes all occurrences:

```kotlin
val minus = mutableListOf("one", "two", "three", "three", "four")
minus -= "three"
println(minus)
minus -= listOf("four", "five")
println(minus)
```

```text
[one, two, three, four]
[one, two, three]
```

One `"three"` survived the first line. In the second, `"five"` is not in the list at all —
harmless, it is simply ignored.

## Read-only is not immutable

A `List` reference pointing at a `MutableList` is a read-only **view**, not a snapshot.
Writes through the mutable reference are visible through it:

```kotlin
val backing = mutableListOf("a", "b")
val readOnlyView: List<String> = backing
backing.add("c")
println(readOnlyView)
```

```text
[a, b, c]
```

<Callout type="warning">
  `readOnlyView` has no `add()` method, yet its contents changed. Read-only means "you
  cannot write through *this* reference", not "this cannot change". For a snapshot that
  genuinely will not move, copy it with `toList()`.
</Callout>

## Updating elements

Sets have no update operation — replacing an element is a removal plus an addition. Lists
and maps do; see
[List-specific](/collection-operations/collection-specific-operations/list-operations) and
[Map-specific](/collection-operations/collection-specific-operations/map-operations)
operations.
